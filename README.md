# Forecasted-Yield-Calculator

**PIS 2026**

**Разработка программного модуля для расчёта потенциальной и достижимой урожайности сельскохозяйственных культур.**  
Проект предусматривает реализацию нескольких методик расчёта (включая модели машинного обучения), работу со справочными таблицами, сохранение истории расчетов, работу с метеорологическими данными и современный пользовательский интерфейс.

---

## 🛠 Технологический стек проекта
* **Язык программирования:** Python 3.10+
* **Графический интерфейс:** PyQt5 (архитектура Event Loop, QSS, QGraphicsDropShadowEffect)
* **Machine Learning:** PyTorch (архитектура сети - Multi-Layer Perceptron)
* **Препроцессинг и данные:** Pandas, NumPy, scikit-learn (StandardScaler, LabelEncoder, joblib)

---

## 📦 Инструкция по развертыванию прототипа (MVP)

**1. Клонирование репозитория:**
```bash
git clone https://github.com/Dyiellcorpdy0/Forecasted-Yield-Calculator.git
cd Forecasted-Yield-Calculator
```

**2. Установка зависимостей:**
```bash
pip install torch pandas numpy scikit-learn joblib PyQt5
```

**3. Подготовка данных и инициализация весов модели:**
Перед первым запуском графического интерфейса необходимо сгенерировать сериализованные файлы весов (`.pth`) и энкодеров (`.pkl`). Скрипт обучения проведет препроцессинг датасета и обучит нейронную сеть:
```bash
python train.py
```

**4. Запуск основного интерфейса (MVP):**
```bash
python main.py
```

**2. Минимально рабочая версия (MVP)**
Для быстрого прототипирования на первых этапах принято решение использовать нормализованные табличные данные (Kaggle Crop Yield Dataset), отфильтрованные по странам с целевым климатом. Интеграция спутниковых данных (Xarray/GeoTIFF) вынесена в последующие итерации.

### Этап 2. Создать техническую основу проекта и работа с видеопотоком
Сформирован базовый каркас приложения на базе фреймворка `PyQt5`. Настроена событийная модель (Event Loop) и потоковый рендеринг графических компонентов (закладывающий основу для динамического обновления тепловых карт и анимаций интерфейса). Создана модульная структура директорий проекта.

### Этап 3. Первая методика расчета
Внедрен базовый (baseline) алгоритм прогнозирования, основанный на эмпирических агроклиматических зависимостях. Реализована обработка входных параметров с учетом единиц измерения (температура в °C, осадки в мм, пестициды в тоннах) и создана логика передачи данных из GUI в расчетный модуль.

### Этап 4. Вторая методика расчета
Разработан модуль машинного обучения с использованием библиотеки `PyTorch`. 
* **Препроцессинг:** Проведена фильтрация исходного датасета с выделением целевых культур (Wheat, Potatoes) и адаптация под умеренно континентальный климат.
* **Архитектура:** Спроектирована полносвязная нейронная сеть (MLP).
* **Обучение:** Модель успешно обучена с использованием оптимизатора Adam и функции потерь MSE. Ошибка на тестовой выборке продемонстрировала высокую способность сети к генерализации.

### Этап 5. Реализация полного набора расчетных методик
Произведено архитектурное разделение бизнес-логики на модуль обучения (`train.py`) и модуль инференса (`main.py`). Внедрена подсистема десериализации весов модели (`yield_model.pth`) в оперативную память графического приложения для обеспечения мгновенного расчета без блокировки основного потока (UI Thread).

### Этап 6. Справочные таблицы
Реализована подсистема работы со справочными и категориальными данными. Внедрено автоматическое кодирование текстовых признаков (названия стран и культур) в тензоры с использованием сериализованных объектов `LabelEncoder` и `StandardScaler` (библиотека `scikit-learn`). Для интерфейса заданы научно-обоснованные дефолтные метеорологические параметры.

### Этап 7. Полноценный интерфейс расчета
Разработан эргономичный пользовательский интерфейс. Внедрен современный Dark Mode посредством `QSS`. Интегрирована система динамической визуальной обратной связи: реализованы эффекты теней (`QGraphicsDropShadowEffect`) и цветовое кодирование результатов прогноза, динамически зависящее от скалярного выхода нейронной сети.

### Этап 8. Первый MVP калькулятора
Выполнена полная интеграция frontend-компонентов (PyQt5) и backend-логики (PyTorch-инференс) в единый программный продукт. Прототип собирается без критических ошибок, полностью покрывает базовый пользовательский сценарий и готов к демонстрации. Завершена первая фаза жизненного цикла проекта.
